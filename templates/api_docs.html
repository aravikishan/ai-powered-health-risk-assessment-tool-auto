API Documentation

Welcome to the API documentation for the AI-Powered Health Risk Assessment Tool.

  • GET /api/profiles: Retrieves all user profiles.
  • POST /api/profiles: Creates a new user profile.
  • GET /api/assessments/{profile_id}: Returns a health risk assessment for a specific user profile.
  • POST /api/assessments: Generates a new health risk assessment based on provided data.
